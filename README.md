# getaura — public web assets

Compiled build output for the AURA client portals, served as the origin for the
Cloudflare Worker in front of `crm.getaura.lu`, `zitha.getaura.lu` and
`blacksheep.getaura.lu`.

This repository is public **only** because GitHub Pages requires it. It contains
no source code, no credentials and no tenant data — just the minified bundle
every visitor's browser already downloads. Application source lives in the
private `dextermex/getaura` repository.

Published from the `gh-pages` branch; do not edit by hand.
